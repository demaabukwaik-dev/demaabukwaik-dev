# Hi, I'm Dema 👋

I'm learning to build AI applications with LLMs, agents and RAG.

When I build with LLMs, I follow one rule: the model suggests, the code decides. The model reads and understands, and plain Python checks every step.

---

## Main projects

**[CV Search RAG](https://github.com/demaabukwaik-dev/cv-search-rag)**

Recruiters describe the person they need in Arabic or English and get a ranked shortlist, with every match linked to the part of the CV it comes from. Includes automatic CV intake from Google Drive, access control per recruiter, and an evaluation with an AI judge.

`PostgreSQL + pgvector` `Gemini` `Streamlit`

**[AI Data Analyst](https://github.com/demaabukwaik-dev/ai-data-analyst)**

Ask questions about any CSV file in plain language and get a sentence, a table and a chart. It asks when a question is unclear and remembers the conversation. This is the second version of Guarded Pandas Agent, rebuilt with a new model and a tool-based approach.

`pandas` `Qwen` `Streamlit` `FastAPI`

**[Guarded Pandas Agent](https://github.com/demaabukwaik-dev/guarded-pandas-agent)**

The first version of the same idea. A model that runs locally writes the pandas code, and Python checks the code before it runs. Only summary results are shown, never raw rows.

`Phi-3.5-mini` `pandas` `FastAPI` `Streamlit`
